# AquaLocal

Локальный голосовой ввод для Windows с NVIDIA GPU. Зажимаешь горячую клавишу, говоришь, отпускаешь — распознанный текст уходит в одно из трёх мест:

| Клавиша | Действие | Куда |
|---|---|---|
| **F19** | вставка в позицию курсора | активное окно (через буфер обмена) |
| **F20** | задача | SingularityApp (REST API) + дубль строкой в Obsidian |
| **F21** | заметка | файл дня в Obsidian |

Аналог Wispr Flow / Aqua Voice, но **полностью локальный**: распознавание идёт на твоей видеокарте через [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (модель `large-v3`), звук никуда не отправляется. В облако уходит только текст задачи — и только когда ты жмёшь F20.

Клавиши, папка Obsidian и параметры разбора настраиваются через `.env`. Работает в фоне, живёт в системном трее, показывает компактный оверлей с осциллограммой во время записи.

## Как это работает

```
                              ┌─────────────────────────────┐
   микрофон ── зажата ──────► │  faster-whisper large-v3     │
              клавиша         │  (CTranslate2, CUDA, FP16)   │
                              └──────────────┬──────────────┘
                                             │ текст
                    ┌────────────────────────┼────────────────────────┐
                    ▼                        ▼                         ▼
              F19: курсор            F20: задача               F21: заметка
             (Ctrl+V в окно)   ┌──────────┴──────────┐      (файл дня .md)
                               ▼                     ▼
                       Obsidian (#задача)     SingularityApp API
                       — чтобы не пропало     — если сеть есть
```

Разбор фразы для F20/F21 — маркерная грамматика на русском: `проект <имя>`, `тег <имя>`, `срок <дата>`, `важно`/`неважно`, `описание <текст>`. Имена проектов и тегов сопоставляются с твоими реальными (нечёткое сравнение + ручные алиасы), потому что Whisper слышит «а семь», а проект называется «А7».

Пример: *«проект ВЛП тег интеграция срок пятницу подготовить смету»* → задача «Подготовить смету» в проекте ВЛП, тег #интеграция, дедлайн — ближайшая пятница.

Подробности грамматики — в docstring `singularity/parser.py`.

## Требования

- **Windows 10/11**
- **NVIDIA GPU** с поддержкой CUDA (проверялось на RTX 3090; хватит любой с ≥4 ГБ VRAM для `large-v3` в FP16)
- **Python 3.12**
- ~3 ГБ свободной VRAM под модель + ~2 ГБ на диске под CUDA-колёса
- Микрофон

CPU-режим технически возможен (правкой `device="cpu"` в `app.py`), но `large-v3` на процессоре работает в разы медленнее — под горячую клавишу непригодно.

**Для SingularityApp (F20)** нужна подписка с доступом к REST API (тариф Elite) и токен.
**Для Obsidian (F21)** ничего не нужно — пишется просто `.md`-файл в указанную папку. Obsidian даже не обязателен, это обычный Markdown.

Что **НЕ** требуется: аккаунт и токен HuggingFace. Модель `large-v3` публичная и качается анонимно. Подробнее — в [DEPLOY.md](DEPLOY.md#huggingface).

## Быстрый старт

```powershell
git clone https://github.com/neo-flashman/aqualocal.git
cd aqualocal

py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

copy .env.example .env
copy singularity\aliases.json.example singularity\aliases.json
notepad .env          # вписать токен Singularity и путь к папке Obsidian

.venv\Scripts\python.exe test_cuda.py   # проверка, что CUDA видна
.venv\Scripts\python.exe app.py         # запуск (появится иконка в трее)
```

Полная пошаговая инструкция с получением токенов, автозапуском и разбором ошибок — **[DEPLOY.md](DEPLOY.md)**.
Как пользоваться голосовыми командами — **[USAGE.md](USAGE.md)**.

## Настройка

Всё в `.env` (шаблон — `.env.example`, там подробные комментарии к каждому параметру). Ключевое:

```ini
# SingularityApp
SNG_TOKEN=<твой токен>
SNG_DEFAULT_PROJECT=            # P-... или пусто = Входящие

# Obsidian
OBS_INBOX_DIR=E:\vaults\my\Входящие
OBS_TASK_TAG=задача             # тег для дублей задач F20

# Горячие клавиши (одиночные или комбинации)
HOTKEY_INSERT=f19
HOTKEY_TASK=f20
HOTKEY_NOTE=f21
```

Хоткеи понимают комбинации в синтаксисе пакета `keyboard`: `ctrl+d`, `alt+shift+1`, `ctrl+alt+space`. Подробности и предостережения — в комментариях `.env.example`.

### Распознавание для других программ (необязательно)

```ini
STT_PORT=8970          # пусто или строки нет — сервер не поднимается
```

С заданным портом поднимается локальный сервер: `POST http://127.0.0.1:<порт>/stt`, тело — байты аудиофайла (ogg/opus, mp3, wav — что понимает PyAV), ответ — `{"text": "…"}`. Распознаёт та же модель, что уже загружена в видеопамять, второй копии не появляется; запросы и горячие клавиши ходят к ней по очереди. Речи в записи нет — `text` пустой, модель не запускается. Слушает только `127.0.0.1`, наружу не выставляется.

## Структура

```
aqualocal/
├── app.py                      главный процесс: STT, хоткеи, трей, оверлей
├── requirements.txt
├── .env.example                шаблон конфигурации
├── start.bat                   запуск с консолью
├── start_aqualocal.vbs         тихий запуск без окна (для автозагрузки)
├── test_cuda.py                проверка доступности CUDA
├── singularity/                интеграция с SingularityApp (F20)
│   ├── sender.py               точка входа + offline-очередь
│   ├── client.py               REST-клиент, кэш НСИ, fuzzy-резолв
│   ├── parser.py               разбор фразы в структуру задачи
│   ├── fetch_openapi.py        выгрузка OpenAPI-схемы (для сверки)
│   └── aliases.json.example    шаблон ручных соответствий имён
├── obsidian/                   запись заметок (F21) и дублей задач
│   └── writer.py               файл дня, offline-очередь, разбор тегов
└── tools/
    └── fix_venv_paths.py       чинит venv после переноса между дисками
```

## Приватность

- **Аудио не покидает машину.** Распознавание — локальное, на GPU.
- В облако (SingularityApp) уходит только **текст задачи** и только по F20.
- **F19 и F21 полностью офлайн.**
- Токен и личные данные (кэш проектов, алиасы) — в `.gitignore`, в репозиторий не попадают.
