# Как пользоваться AquaLocal

Три режима, каждый на своей клавише. Механика одна: **зажал клавишу → говоришь → отпустил**. Пока держишь — идёт запись (внизу экрана появляется оверлей с осциллограммой), отпустил — распознавание и действие.

Клавиши ниже — по умолчанию (F19/F20/F21). Если ты переназначил их в `.env`, подставь свои.

---

## F19 — вставка в курсор

Самый простой режим. Распознанный текст вставляется туда, где стоит курсор — в любое поле ввода активного окна (мессенджер, редактор, адресная строка, поле формы).

Фраза берётся как есть, без разбора команд. Диктуешь — получаешь текст.

> Технически: приложение подменяет буфер обмена, шлёт Ctrl+V и возвращает буфер обратно. Так что твоя копия в буфере не теряется.

**Оверлей: красный.**

---

## F20 — задача в SingularityApp

Распознанная фраза разбирается на структуру задачи и уходит в SingularityApp через API. Одновременно строка дублируется в дневник Obsidian с тегом `#задача` — чтобы задача не пропала, если интернета нет или API недоступен.

Фраза понимает **команды-маркеры**. Их можно ставить в любом порядке в начале фразы, а всё, что осталось после них, становится заголовком задачи.

### Маркеры

| Скажи | Что делает |
|---|---|
| `проект <имя>` | кладёт задачу в проект (по имени, нечёткое сопоставление) |
| `тег <имя>` | вешает тег (можно несколько раз) |
| `срок <дата>` / `до <дата>` / `дедлайн <дата>` | дедлайн |
| `на <дата>` / `дата <дата>` | дата начала |
| `важно` / `срочно` | высокий приоритет |
| `неважно` / `потом` | низкий приоритет |
| `описание <текст>` / `заметка <текст>` | заметка к задаче (забирает весь хвост фразы) |

Служебные слова перед маркером проглатываются: можно говорить «**в** проект», «**с** тегом».

### Даты

Понимает: `сегодня`, `завтра`, `послезавтра`, день недели (`пятницу`, `среду`...), `через 3 дня` / `через неделю` / `через 2 месяца`, `15 августа`, `15 августа 2026`, `24.12`, `24.12.2026`.

Дата без года, которая уже прошла в этом году, автоматически переносится на следующий.

### Примеры

| Говоришь | Получаешь |
|---|---|
| «купить хлеб» | задача «Купить хлеб» во Входящих |
| «проект ВЛП тег интеграция срок пятницу подготовить смету» | «Подготовить смету» → проект ВЛП, #интеграция, дедлайн пятница |
| «важно срочно позвонить в банк» | «Позвонить в банк», высокий приоритет |
| «завтра забрать документы описание из бухгалтерии» | «Забрать документы», старт завтра, заметка «из бухгалтерии» |

### Про имена проектов и тегов

Whisper слышит звук, а не твои названия. «А7» он распознает как «а семь», «ВЛП» как «в эл пэ». Поэтому имена сопоставляются **нечётко** с твоим реальным списком (он подтягивается из аккаунта и кэшируется).

Если что-то стабильно не находится — добавь ручное соответствие в `singularity/aliases.json`:
```json
{
  "а семь": "P-xxxxxxxx",
  "митинг ассистент": "P-yyyyyyyy"
}
```
Список своих ID: `.venv\Scripts\python.exe -m singularity.sender --list`.

Если проект/тег так и не распознался — задача всё равно создаётся (во Входящих), а что не сопоставилось — дописывается в её заметку, чтобы ты увидел и поправил.

**Оверлей: синий.** После отправки на ~2 сек показывается подтверждение с текстом задачи.

## F21 — заметка в Obsidian

Быстрая строка в дневник. Уходит в файл текущего дня в папке `OBS_INBOX_DIR`.

- Файл называется по дате: `2026-07-27.md`.
- Нет файла — создаётся (с заголовком `# 2026-07-27`).
- Есть — строка дописывается в конец.
- Формат строки: `- ЧЧ:ММ⇥ Текст #теги` (время, таб, текст).

Из маркеров работает только `тег <имя>` (в любом месте фразы) — остальная грамматика тут не нужна, заметка есть заметка.

### Примеры

| Говоришь | Строка в файле |
|---|---|
| «мысль про рефакторинг клиента» | `- 14:30	Мысль про рефакторинг клиента` |
| «тег дом заказать бетон на фундамент» | `- 14:31	Заказать бетон на фундамент #дом` |
| «позвонить Владимиру тег влп тег созвон» | `- 14:32	Позвонить Владимиру #влп #созвон` |

Теги для заметок сопоставляются с тем же списком, что и для задач (`#Курс`, а не `#курс`), если включено `OBS_RESOLVE_TAGS=1`. Пробелы в тегах Obsidian не поддерживает, поэтому «Meeting Assistant» станет `#Meeting-Assistant`.

**Оверлей: зелёный.**

## Что если нет сети / API недоступен

Ничего не теряется:

- **F20:** задача сразу пишется в дневник (`#задача`), а попытка отправки в API при сбое кладёт её в `singularity/queue.jsonl`. При следующей удачной отправке очередь досылается автоматически. Вручную: `.venv\Scripts\python.exe -m singularity.sender --flush`.
- **F21:** если папка Obsidian недоступна (внешний диск отключён), заметка уходит в `obsidian/queue.jsonl` и допишется, когда папка снова появится. Причём в файл того дня, когда ты её продиктовал, — время берётся из записи.

## Обратная связь

Приложение работает без окна, поэтому всё показывает плашка внизу экрана. Звуковых сигналов нет.

- **идёт запись** — волна, реагирующая на голос; цвет по режиму (красный — вставка, синий — задача, зелёный — заметка)
- **идёт распознавание** — надпись с бегущими точками; если затянулось дольше 3 секунд, добавляется счётчик
- **готово** — что записано или отправлено (например, название задачи)
- **не расслышал** — речи в записи не нашлось; Whisper при этом даже не запускался
- **ошибка** — красная точка и текст: ушло в очередь, сбой распознавания

## Проверка без микрофона

Разбор фразы можно прогнать из командной строки, не диктуя:

```powershell
# как распарсится задача (без отправки)
.venv\Scripts\python.exe -m singularity.sender --dry "проект дом срок завтра заказать окна"

# как распарсится заметка
.venv\Scripts\python.exe -m obsidian.writer --dry "тег 1с посмотреть вебинар"

# только разбор грамматики, без резолва имён
.venv\Scripts\python.exe -m singularity.parser "проект ВЛП тег интеграция срок пятницу смета"
```

Удобно, чтобы подобрать формулировки под свою грамматику.
