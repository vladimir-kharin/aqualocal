# CLAUDE.md

## О проекте

AquaLocal — локальный голосовой ввод для Windows: удержание горячей клавиши → запись с микрофона →
распознавание `faster-whisper large-v3` на GPU → текст уходит в курсор (F19), в SingularityApp (F20)
или в файл дня Obsidian (F21). Пользовательская документация — `README.md`, `DEPLOY.md`, `USAGE.md`.

Репозиторий — **форк** `neo-flashman/aqualocal` (`upstream`), наш `origin` — `vladimir-kharin/aqualocal`,
ветка `master`. Репозиторий публичный: секреты, тексты продиктованного и названия личных проектов
в него не попадают.

## Окружение и команды

Python 3.12 в `.venv`, всегда вызывать интерпретатор по полному пути, без `activate`:

```powershell
.venv\Scripts\python.exe app.py                                  # запуск с консолью (видны ошибки CUDA)
.venv\Scripts\python.exe test_cuda.py                            # доступна ли CUDA для CTranslate2
.venv\Scripts\python.exe -m singularity.sender --dry "…"         # разбор фразы без создания задачи
.venv\Scripts\python.exe -m obsidian.writer --dry "…"            # разбор заметки без записи
.venv\Scripts\python.exe tools\fix_venv_paths.py                 # починка venv после переноса
```

- Тестов и линтера в проекте нет; проверка правок — CLI-режимы модулей выше и запуск приложения.
- `start.bat` / `start_aqualocal.vbs` запускают через `pythonw.exe` — **у него нет stderr**, поэтому
  при отладке запускать `python.exe`, а причины искать в `aqualocal.log`.
- Правка `.env` требует перезапуска: конфигурация читается один раз при импорте.
- Временные файлы — во временной папке вне репозитория, не в его корне.

## Правила правок

- Комментарии, сообщения лога и коммиты — на русском. Коммиты — Conventional Commits.
- `setup_nvidia_paths()` вызывается **до** импорта `faster_whisper` (`app.py:54-92`) — порядок
  импортов в `app.py` не переставлять.
- Пакеты `singularity/` и `obsidian/` независимы друг от друга и от `app.py` (у каждого свой
  `load_env()`, свой CLI). Не связывать их общими модулями без нужды.
- Новые настройки — в `.env` + `.env.example` с комментарием и дефолтом в коде; приложение обязано
  стартовать с пустым `.env`.
- Из рабочих потоков нельзя трогать виджеты tkinter — обратная связь только через `flash(...)`.
- Любая доработка, отправляющая данные наружу (облачные модели, телеметрия), меняет обещание
  приватности из `README.md` — согласовывать с владельцем.
