# Задачи AquaLocal

Оперативные задачи проекта. Каждая задача — папка `docs/tasks/<ИмяЗадачи>/` с `README.md`
(суть, факты, план, статус). Рядом в папке задачи могут лежать черновики, замеры, скрипты проверки.

**Это не база знаний.** Устройство системы и принятые решения живут в `docs/kb/`
(точка входа — [docs/kb/карта.md](../kb/карта.md)). Из завершённой задачи в базу знаний выносится
только обобщённое знание — отдельной карточкой, по правилам `docs/kb/регламент.md`.

**Статусы:** `[ ]` новая · `[~]` в работе · `[>]` на проверке у владельца · `[?]` приостановлена ·
`[x]` готово (уезжает в `docs/archive/`).
**Приоритет:** 🔴 `@p1` высокий · 🟡 `@p2` средний · 🟢 `@p3` низкий.

## Как заводится новая задача

1. Папка `docs/tasks/<ИмяЗадачи>/` (кириллица, без пробелов, в стиле существующих).
2. `README.md` с шапкой: тип, ответственный, статус, дата постановки; затем «Суть», «Проверенные
   факты», «План», «Открытые вопросы».
3. Строка в таблице выше.
4. Знание, добытое по ходу («оказывается, VAD режет первые 200 мс»), — не в задачу, а карточкой
   в `docs/kb/` после подтверждения владельцем.
