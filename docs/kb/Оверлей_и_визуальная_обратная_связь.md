# Оверлей записи и визуальная обратная связь

Белая «пилюля» 300×56 внизу по центру экрана (на 90 px выше нижнего края) — класс `RecordingOverlay`
(`app.py:513`). Рисуется на `tk.Canvas` вручную: скруглённая подложка, мигающая точка, столбики волны.

## Четыре состояния

| Состояние | Условие | Что видно |
|---|---|---|
| скрыт | ничего не происходит | `alpha = 0.0` |
| запись | `is_recording` | точка + бегущая волна по громкости (`_redraw`) |
| распознавание | `is_transcribing` | «идёт распознавание…», после 3 с — счётчик секунд (`_redraw_status`) |
| подтверждение | пришло сообщение в `flash_queue` | точка + текст результата, 1.8 с по умолчанию (`_redraw_flash`) |

Цвет — по режиму (`accent()`, `app.py:555`): красный `#e53935` — вставка в курсор, синий `#2979ff` —
задача, зелёный `#2e7d32` — заметка. Неуспех всегда красный, независимо от режима.

Перерисовка — `root.after(33, self._tick)`, ~30 кадров/с (`app.py:635-673`). Волна: список из 34
значений, каждый кадр сдвигается влево, справа добавляется `min(1.0, current_volume * 14)` —
коэффициент 14 подобран под типичный уровень микрофона.

## Решения, которые легко сломать при доработке

**Скрытие через `alpha`, а не `withdraw()`** (`app.py:535`, `app.py:669`).
**Почему:** `withdraw`/`deiconify` при показе дёргает фокус, и первая же буква после диктовки может
уйти не в то окно. Прозрачность окно не пересоздаёт — фокус остаётся у активного приложения.
**Как применять:** прятать оверлей только через `attributes('-alpha', 0.0)`.

**Click-through и неактивируемость** — `_make_clickthrough()` (`app.py:559-572`) ставит через WinAPI
расширенные стили `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TRANSPARENT`.
**Почему:** плашка висит поверх рабочей области; без этих флагов она перехватывала бы клики и мелькала
бы в Alt+Tab и на панели задач.
**Как применять:** стили ставятся один раз после `update_idletasks()`; если окно пересоздаётся —
вызывать заново. Родительский hwnd берётся через `GetParent(winfo_id())` — для окна с
`overrideredirect(True)` это обязательный шаг.

**Прозрачный фон** — `-transparentcolor '#0f0f0f'` (`app.py:534`). Этот цвет не должен встречаться
в рисунке, иначе в плашке появятся дырки.

**`-topmost True` выставляется один раз при создании** (`app.py:533`). Практика показала, что этого
недостаточно: полноэкранные и «всегда сверху» окна других программ перекрывают плашку, и Windows
не возвращает её наверх сам. Доработка — задача `docs/tasks/ОверлейПоверхОкон/`.

## Звуков в программе нет — намеренно

Коммит 0eb00b7 заменил звуковые сигналы визуальной обратной связью. **Почему:** приложение работает
во время диктовки и разговоров, звуки мешали и терялись в наушниках; плашка сообщает и факт, и
результат (в какой проект ушла задача, в какой файл записана заметка).
**Как применять:** любую новую обратную связь давать через `flash(text, ok, sec)` (`app.py:176`) —
он потокобезопасно кладёт сообщение в `flash_queue`, UI подхватывает его сам. Из рабочих потоков
**нельзя** трогать виджеты напрямую.

Тексты плашек короткие: длиннее 34 символов обрезаются многоточием (`app.py:611`).
