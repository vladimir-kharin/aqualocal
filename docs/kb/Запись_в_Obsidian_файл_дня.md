# Запись в Obsidian: файл дня

Приёмник для F21 (заметка) и для дубля задачи по F20. Obsidian как программа не нужен — пишется
обычный Markdown в папку `OBS_INBOX_DIR`.

- имя файла — дата по `OBS_DATE_FMT` (`2026-08-13.md`); нет файла — создаётся с заголовком
  `OBS_HEADING` (`# 2026-08-13`);
- строка — по `OBS_LINE_FMT`, по умолчанию `- {time}\t{text}`, теги дописываются в конец:
  `- 20:31→Купить окна #дом #задача`;
- папки нет — создаётся; создать не удалось — `ObsidianError`, и фраза уходит в очередь
  (см. [[Оффлайн_очереди_и_сохранность_фраз]]).

## Детали, которые не видно с первого взгляда

**Файл дописывается аккуратно.** Перед записью проверяется последний байт файла: если предыдущая
строка осталась без перевода строки (Obsidian при ручной правке это допускает), сначала дописывается
`\n`, иначе наша запись приклеилась бы к чужой (`writer.py:216-222`). Открытие всегда с
`newline="\n"` — в vault не должно быть смеси переводов строк.

**Теги сверяются с кэшем SingularityApp, но без сети.** Маркеры `тег/тэг/с тегом` берутся импортом
из `singularity.parser` — чтобы слово «тег» означало одно и то же в обоих режимах (`writer.py:86-95`).
Имя тега прогоняется через `resolve_tag` по локальному `singularity/cache.json`.
**Почему:** иначе «курс» и «Курс» расползлись бы в vault в два разных тега. Не нашли в кэше или
`OBS_RESOLVE_TAGS=0` — пишем как произнесено, взяв ровно одно слово (иначе в тег утащит полфразы).

**`slug()` чистит тег под Obsidian** (`writer.py:115-121`): пробелы → дефисы, пунктуация выбрасывается,
**чисто цифровой тег обесценивается в пустую строку** — Obsidian такие не подсвечивает.

**Импорт из `singularity` — мягкий.** Пакет недоступен (нет токена, развалилась интеграция) —
модуль подставляет локальный минимальный набор маркеров и работает дальше. Запись заметок не должна
зависеть от трекера; свой `load_env()` здесь по той же причине — см. [[Конфигурация_через_env]].

**Дубль задачи отличается тегом.** F20 передаёт `extra_tags=[OBS_TASK_TAG]` (по умолчанию `задача`);
теги-маркеры ставятся впереди распознанных, дубликаты схлопываются с сохранением порядка
(`writer.py:194-202`).

## Проверка без микрофона

```powershell
.venv\Scripts\python.exe -m obsidian.writer --dry "тег 1с посмотреть вебинар"   # покажет файл, строку, теги
.venv\Scripts\python.exe -m obsidian.writer "тег дом купить мастику"            # записать
.venv\Scripts\python.exe -m obsidian.writer                                     # справка + текущий OBS_INBOX_DIR
```
