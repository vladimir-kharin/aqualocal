# Локальный STT-сервер

Приложение может отдавать распознавание другим программам на той же машине — той же моделью, что
уже лежит в видеопамяти, без второй копии.

Включается одной строкой в `.env`:

```ini
STT_PORT=8970      # пусто или строки нет — сервер не поднимается вовсе
```

## Контракт

```
POST http://127.0.0.1:<порт>/stt
тело: байты аудиофайла (ogg/opus из Telegram, mp3, wav — всё, что понимает PyAV)
ответ: {"text": "..."}   HTTP 200
       {"error": "..."}  HTTP 500
       400 — пустое тело, 404 — любой путь кроме /stt
```

Перекодировать снаружи не нужно: `decode_audio` из faster-whisper сам приводит вход к 16 кГц моно
(`app.py:350`). Речи в записи нет — модель не запускается вовсе, возвращается пустой `text`:
дешёвый VAD-детектор Silero отрабатывает на процессоре за 10–20 мс (`app.py:352`).

Пример проверки:

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8970/stt -Method Post -InFile .\test.ogg
```

## Что заложено в решении

- **Слушает только `127.0.0.1`** (`app.py:375`) — наружу не выставляется, аутентификации нет и не
  подразумевается. Открывать порт на `0.0.0.0` без токена нельзя: это доступ к чужому микрофонному
  контуру и к видеокарте.
- **Общий замок с микрофоном** — `model_lock` (`app.py:419`): запросы сервера и горячие клавиши
  ходят к модели по очереди. Пока идёт чужой запрос, диктовка ждёт (и наоборот). Сервер многопоточный
  (`ThreadingHTTPServer`), поэтому без замка два `transcribe` подрались бы за видеопамять.
- **Свой лог вместо stderr** — `log_message` заглушён (`app.py:371`), у `pythonw` нет stderr.
  Каждый запрос пишется строкой `[stt] <N> сек аудио за <M> с: <текст>`; сегодня это единственный
  источник замеров скорости, см. [[Производительность_распознавания_на_GPU]].
- Порт не поднялся (занят) — приложение не падает, пишет ошибку в лог и работает без сервера
  (`app.py:376-378`).

Известные потребители: голосовые режимы соседних инструментов владельца (например, обработка
голосовых сообщений). Проект `task_switcher` — кандидат на использование этого же порта.
